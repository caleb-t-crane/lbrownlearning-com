# Leadership Training & Coaching | LBrown Learning

Rebuilt from https://lbrownlearning.com/ by WebReUp on 2026-09-05.

- Framework: Next.js (App Router, static export) + Tailwind CSS v4
- Deploy: Netlify (`npm run build`, publish `out/`). Forms use Netlify Forms.
- Content edits: open a change request; each request becomes a branch + pull request with a Netlify deploy preview.

## Local development

```bash
npm install
npm run dev
```
